# 可视化深度研究工作区实施计划

> 按测试驱动顺序实施；每项先增加失败测试，再写最小实现并回归。

## 1. 平台研究模板契约

- 新增 `backend/app/services/research/templates.py`，集中定义 GitHub、arXiv 与 Hugging Face 的标题、引用章节、研究焦点和 Mermaid 约束说明。
- 扩展引用验证测试，覆盖三种精确模板、Mermaid 缺失/重复/危险指令和 fenced code 段落处理。
- 让报告生成提示与验证器共享同一模板来源，避免提示词与校验漂移。

## 2. 研究编排接线

- 在 AI 服务测试中断言不同平台收到不同模板和专业研究要求。
- 在编排器生成与持久化检查点都传入来源平台。
- 回归模型格式重试、报告检查点和标签降级路径。

## 3. 安全 Mermaid 渲染

- 添加 Mermaid 依赖并实现按需加载的 `MermaidDiagram`。
- 扩展 `SafeMarkdown` 的代码块渲染：仅 `language-mermaid` 进入图示组件，其余代码保持原行为。
- 测试安全初始化、成功渲染、错误回退和普通 Markdown 安全策略。

## 4. 研究速览与双栏阅读

- 新增纯解析器，从新旧研究 Markdown 提取摘要、核心判断、局限、启发、章节数和引用数。
- 新增 `ResearchOverview`，展示结论先行的摘要与研究判断卡。
- 改造 `EditorWorkspace`：研究页默认速览，可切换全文编辑；改造 `PreviewPanel` 标题；调整标签管理顺序和响应式样式。
- 添加交互测试，确保默认速览、编辑保存、旧报告兼容和非研究标签不回归。
